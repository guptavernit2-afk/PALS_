# Agent Behavior Rules

Please adhere to the following project-wide rules when working in this workspace:

- Do not choose a framework or generate application code until the official problem statement is available.
- Prefer clean architecture, reusable components, and maintainable code.
- Prioritize distinctive, premium UI design rather than generic template layouts.
- Keep dependencies minimal and verify library compatibility before installation.
- Test the application in the browser and fix visual defects when a UI is implemented.
- Never overwrite working files or perform destructive Git operations without approval.
- Never commit credentials, API keys, or secrets.
- Work incrementally and report what changed.
